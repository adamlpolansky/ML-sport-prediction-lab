# Data sources

The synthetic demos use deterministic fictional generation authored by Adam Luboš Polanský. The
separate EPL 2026/27 Matchweek 1 pack uses only revision-pinned OpenFootball fixture facts under
CC0-1.0; see [forecast provenance](forecast_provenance.md) and
[data provenance and licences](data_provenance_and_licenses.md) for the complete redistribution
boundary.

No live or cached external source is needed by the package, tests, CI, demos, or forecast validator.
